# PROJECT CONTEXT — Dengar.in

**Product Name**: Dengar.in  
**Tagline / Positioning**: *"Pendamping Mental Well-being Anonim Berbasis AI"*  
**Target Group**: Users aged 15–54 across Indonesia  
**Competition**: MindCraft Web Competition 2026 (Theme: *Building Digital Solutions for Mental Well-being*)  

---

## 1. Executive Summary

Dengar.in is an anonymous, context-aware digital companion designed to bridge the critical gap between psychological distress, real-world context, concrete action, and continuous follow-up. 

Dengar.in explicitly positions itself as a **COMPANION**, not a diagnostic clinic or replacement for licensed mental-health professionals. It provides guided, structured, self-directed intervention pathways (2–4 weeks), daily micro-missions, mood check-ins, local-first private journaling, and verified professional escalation.

---

## 2. The Core Problem

Mental distress does not happen in a vacuum. Most solutions provide either generic static articles or uncontrolled AI chatbots that simulate pseudo-therapy. The actual gap consists of 5 disconnected links:

```
[ 1. Emotional Distress ]
          ↓
[ 2. Real-Life Context (School / Campus / Work / Finance / Relationship / Family) ]
          ↓
[ 3. Concrete Next Action (Micro-mission / grounding / reframing) ]
          ↓
[ 4. Appropriate Support (Verified professional hotlines & directories) ]
          ↓
[ 5. Continued Follow-up (Check-ins / streaks / weekly report) ]
```

---

## 4. Key Differentiators

1. **Strictly Anonymous by Design**: No email, phone number, or KYC required. Identity is anchored on a cryptographic UUID and a 12-word recovery mnemonic.
2. **Deterministic Safety-First Architecture**: Crisis screening is 100% deterministic (zero LLM reliance for life-safety).
3. **AI as an Orchestrator, Not a Therapist**: The AI cannot invent therapies or chat indefinitely; it selects from a validated action schema.
4. **Financial Mental Burden Domain**: Tailored support for predatory lending (pinjol ilegal) anxiety and sandwich generation pressure.
5. **Local-First Journal**: User private thoughts stay on their device; sensitive reflections are never pushed to LLM logs.
6. **Follow-Up Orientation**: Progress is measured across continuous 2–4 week intervention paths with weekly reports.
